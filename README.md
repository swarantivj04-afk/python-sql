 data analysis for E-commerce site data using python 

This project analyzes an e-commerce dataset using SQL and Python to extract business insights such as revenue trends, customer retention, top-performing products, and regional performance.

## Objectives
- Calculate total sales per category
- Identify top 3 customers per year
- Analyze year-over-year growth
- Calculate customer retention rate
- Visualize sales trends

  ## Tools & Technologies
- SQL (MySQL / SQLite)
- Python (jupyter notebook)
- Pandas (data manipulation & analysis)
- Matplotlib (visualization)
