 data analysis for E-commerce site data using python 

This project analyzes an e-commerce dataset using SQL and Python to extract business insights such as revenue trends, customer retention, top-performing products, and regional performance.

## Objectives
- Calculate total sales per category
- Identify top 3 customers per year
- Analyze year-over-year growth
- Calculate customer retention rate
- Visualize sales trends

  ## Tools & Technologies
- SQL (MySQL / SQLite)
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

- ## Dataset
- https://drive.google.com/drive/folders/1IfC8yU0_kyKFBcRC6JxV9n-N7WS9_qNu?usp=drive_link
The dataset contains:
- Orders table
- Customers table
- Order items table
- Products table
- orders table
- geolocation
- sellers table

	## Key SQL Analysis and visualization
- Total revenue per year
- Year-over-Year Growth using LAG()
- Customer retention within 6 months
- Top 3 customers by yearly spending
- Sales per category
